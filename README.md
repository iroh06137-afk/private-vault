# 保管庫

自分専用の非公開メディアギャラリー（PWA）です。

**アプリ URL:** https://iroh06137-afk.github.io/private-vault/
写真と動画は Supabase の **非公開バケット** に置かれ、短い期限付き URL でのみ表示します。このリポジトリにはアプリのコードだけがあり、メディアファイルは含まれません。

## 使い方（初回）

1. アプリを Safari（iPhone）またはブラウザ（Mac）で開く。
2. 「初めて使う（アカウント作成）」から、自分のメールアドレスと 8 文字以上のパスワードで登録する。
3. 確認メールが届いたら、メール内のリンクを開いてからログインする（迷惑メールも確認）。
4. ログインできたら、右上の ＋ から写真や動画を追加できる。

**アカウントは自分で作ってください。** こちらではメールアドレスを推測して作っていません。

### 登録後にやっておくこと（重要）

いまは「自分の行だけ読める」権限制御になっています。他人が同じアプリで新規登録しても、あなたのファイルは見えません。それでも登録を自分一人に固定するため、最初のログインが成功したあと、次を行ってください。

1. [Supabase の Authentication 設定](https://supabase.com/dashboard/project/pewywvkfmlnqgsqcdmhs/auth/providers) を開く。
2. Email プロバイダの **Allow new users to sign up** をオフにする。

必要なら、同じ画面でその後の案内も確認できます。

### iPhone のホーム画面にアプリのように置く

1. **Safari** でアプリを開く（Chrome では追加メニューが出ません）。
2. ログインする。
3. 共有ボタン（四角から矢印が出ているアイコン）をタップする。
4. **ホーム画面に追加** を選び、名前は「保管庫」のままで追加する。
5. ホーム画面のアイコンから開く。

## 料金

- Supabase プロジェクト `private-vault`（東京リージョン）は **無料プランで作成**しており、追加の月額料金はありません。
- 無料プランの容量（目安）：ストレージ約 1 GB、1 ファイルあたり最大 200 MB。容量を超えるとアップグレードが必要になることがあります。
- 既存の「ぬいもん」用プロジェクトには、バケットもテーブルもユーザーも作っていません。

## セキュリティ

- バケット `vault` は非公開です。匿名アクセスでは一覧・取得・追加ができません。
- メディアはサインイン中の所有者のフォルダにだけ置かれ、期限付きの署名 URL でのみ配信します。
- 公開してよい API キー（anon / publishable）だけをアプリに含めています。
